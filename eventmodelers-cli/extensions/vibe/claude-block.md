This project is **model first, code second**: every change is put on the event model on the board before the code follows, whatever the person asks for and however they phrase it. Code changed outside this flow is detected as drift and synced, never left to rot. Only modules that were analysed (`/analyze-code-base`, one chapter at a time) are governed; their analysis log is `.vibe/baseline/`. **At the first request of a session, before anything else, run the session-start sweep from `start-vibe-session` yourself** — the person never has to ask for it (`/start-vibe-session` only re-runs it by hand).

**Before you change any code**, run `{{CLI}} vibe check <the files you are about to change> --json` (find the target code first; with no paths it checks every changed file). Then follow `vibe-control` (`/vibe-control`):

- `governed` — the chapter is analysed and unchanged since: **model first, code second, whatever the person says** — put the requested change on the board model, then change the code to match (below). Never change the code first and translate afterwards.
- `drifted` — an earlier change was never translated onto the model: ask whether to translate it first (`vibe-translate`) or carry on.
- `uncovered` — **do not just carry on and do not stop dead: ask the person** — analyse it first (they run `/analyze-code-base` for that chapter themselves; it is an interview), continue without the model this time, or never ask about this folder. Record the answer with `{{CLI}} vibe answer`.
- `free` — not modeled; change it as asked.

**In a governed chapter**, first model the requested change on the board (the matching modeling skills, `vibe-translate`'s rules), then change the code so it matches the model, then `{{CLI}} vibe baseline advance --chapter "<title>"`. `vibe-translate` of a code diff is only the catch-up for `drifted` code. The analysis log lives in the baseline file; the board's `Legacy Sources` note is rendered from it (`vibe baseline render`) — never edit the note by hand and never read it back. Nothing is ever written into the source code for this.
